Guía de Despliegue en GitHub Pages + Proxy GTFS-RT

Arquitectura estática gratuita para monitorizar Renfe, Iryo, Ouigo y Adif

Paso 1: Subir este archivo a tu repositorio Guarda este código como index.html en la raíz de tu repositorio de GitHub y activa Settings → Pages → Source: Deploy from a branch (main). Tu web estará online en https://tu-usuario.github.io/tu-repo/.
Paso 2: Proxy CORS gratuito en Cloudflare Workers (Tiempo Real Renfe GTFS-RT)

Evita el bloqueo CORS del navegador al consultar https://gtfsrt.renfe.com/vehicle_positions.json y cachea respuestas durante 15 segundos.

export default {
  async fetch(request) {
    const url = new URL(request.url);
    const feed = url.searchParams.get("feed") || "vehicle_positions.json";
    const allowedFeeds = ["vehicle_positions.json", "trip_updates.json"];
    const targetFeed = allowedFeeds.includes(feed) ? feed : "vehicle_positions.json";

    const response = await fetch(`https://gtfsrt.renfe.com/${targetFeed}`, {
      cf: { cacheTtl: 15, cacheEverything: true },
      headers: { "User-Agent": "LAV-Radar-GitHubPages/1.0" }
    });

    const body = await response.text();
    return new Response(body, {
      headers: {
        "Content-Type": "application/json; charset=utf-8",
        "Access-Control-Allow-Origin": "*",
        "Cache-Control": "public, max-age=15"
      }
    });
  }
};
Paso 3: Workflow de Despliegue Automático (`.github/workflows/deploy.yml`)

Despliega automáticamente cada vez que hagas git push a la rama main.

name: Desplegar Monitor LAV en GitHub Pages

on:
  push:
    branches: ["main"]
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

jobs:
  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    steps:
      - name: Checkout repositorio
        uses: actions/checkout@v4
      - name: Configurar GitHub Pages
        uses: actions/configure-pages@v5
      - name: Subir artefacto estático
        uses: actions/upload-pages-artifact@v3
        with:
          path: '.'
      - name: Publicar en GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
